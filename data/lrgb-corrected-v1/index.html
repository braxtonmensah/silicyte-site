What the release records

The release metadata records 0 of 2,331 test rows with a training sequence at Levenshtein ratio 0.80 or above. The same run records 65.29% on LRGB's original split. These measure sequence overlap; they do not measure how much any model's score changes.

The split uses transitive single linkage, assigns whole clusters to folds, and retains 10,873 training, 2,331 validation and 2,331 test rows. It records 6,339 clusters and seed 20261017.

How to use the file

The JSON contains splits.train, splits.val and splits.test. Each is a list of zero-based row indices into LRGB's peptide_multi_class_dataset.csv.gz in its original file order. Update your loader to read this JSON format; it is not a pickle file.

The source-data MD5 is 701eb743e899f4d793f0e13c8fa5a1b4; the original-split MD5 is 5a0114bdadc80b94fc7ae974f13ef061. Check your inputs before using these indices.

Inspect the builder and verification code. The release notes describe the control and method.

Scope and licence

This download contains split indices and metadata, not the underlying molecular dataset. The split release is CC BY 4.0; the underlying LRGB data retains its own CC BY-NC 4.0 terms.

No model-performance improvement follows from the overlap count alone. The 0.80 threshold is a stated evaluation choice, not a universal guarantee of independence. Computational results do not establish biological activity or clinical usefulness.
